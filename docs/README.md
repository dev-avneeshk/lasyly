# Documentation

Project documentation for Lasyly / Betroom. The repo root keeps only the
essential entrypoints (`README.md`, `AGENTS.md`, `CLAUDE.md`); everything else
lives here.

## Structure

```
docs/
├── product/     Product & positioning
├── reports/     Point-in-time audits and verification reports
├── SUPABASE_AUTH_CONFIG.md   Supabase auth setup reference
└── nba-ranking-engine.md     NBA ranking engine design
```

## Product (`product/`)

| File | What it is |

| [WHAT-WE-DO.md](./product/WHAT-WE-DO.md) | Plain-language description of the product |

## Reports (`reports/`)

Snapshots from specific engineering and legal reviews. These are historical
records — they reflect the state of the codebase at the time they were written
and are not kept continuously up to date.

| File | What it is |
| --- | --- |
| [CODE_AUDIT.md](./reports/CODE_AUDIT.md) | Evidence-based repository audit |
| [REMEDIATION_REPORT.md](./reports/REMEDIATION_REPORT.md) | Remediation work following the audit |
| [FINAL_ASSURANCE_REPORT.md](./reports/FINAL_ASSURANCE_REPORT.md) | Final production assurance review |
| [PRODUCTION_SECURITY_VERIFICATION.md](./reports/PRODUCTION_SECURITY_VERIFICATION.md) | Production security baseline verification |
| [LEGAL_COPY_AUDIT.md](./reports/LEGAL_COPY_AUDIT.md) | Legal copy audit and rewrite |
